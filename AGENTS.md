# AGENTS.md

## Commit messages

- Conventional Commits, one line, no body: `<type>: <lowercase imperative summary>`
- Types in use: `ci`, `feat`, `fix`, `docs`, `test`, `refactor`, `chore`.
- `main` only takes commits through a squash-merged pull request, so the pull request
  title becomes the commit title with ` (#<n>)` appended. Rewrite it before merging.
- Merging needs one approval from another member and a green `ci` check.

## Code

- English in commit messages, comments, step names and file names. `LAB1.md` is the only
  Chinese file.
- `make fmt-check vet test` must pass; `gofmt` clean.
- Standard library only.
- In workflows, route `github` context values through `env:`; never interpolate
  `${{ ... }}` into `run:`.

## Files not to touch

- `Makefile` — the `tar` flags and the `dist/<name>_<version>_<os>_<arch>/` layout are what
  make the artifact reproducible and readable by `scripts/trace.sh`.
- `scripts/trace.sh` — verbatim from the course template.
- `BUILD_INFO` — generated by `make package`; never hand-edit, never hand-write `commit`.
- `.github/workflows/ci.yml` — keep the job named `ci`; add no `paths` filter.
- `LAB1.md` — fill it in, keep it Chinese, don't restructure the course's sections.
- Release assets of an already published version — never replaced.
